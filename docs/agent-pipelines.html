Pi Agent Pipelines

This page documents the executable agents and owner routing model. Diagrams are rendered with Mermaid in the browser.

Agent inventory

AAD owner/support agents

aad-root-owner owns multi-step or multi-slice root work. aad-slice-owner owns one slice. aad-explorer and aad-auditor provide evidence and verification audit support.

AAD worker agents

aad-implementer implements scoped tasks and aad-failure-classifier classifies failed attempts.

Browser automation

chrome-browser-agent uses the browser-chrome skill and MCP browser servers, defaulting to disposable headless Chrome unless profile/auth state is explicitly needed.

Top-level routing map

Use this map for terminal routing. Skills are runbooks/support and do not replace the AAD owner hierarchy.

Default choices from the terminal main assistant.

flowchart TD
  Request["Human / Pi request"] --> Trivial{"Trivial one-step edit, question, or check?"}
  Trivial -- "yes" --> Terminal["Terminal main assistant handles directly"]
  Trivial -- "no" --> SingleSlice{"Clear small / single-slice AAD change?"}
  SingleSlice -- "yes" --> SliceOwner["aad-slice-owner\nown one slice"]
  SingleSlice -- "no" --> RootOwner["aad-root-owner\nroot owner for unclear, multi-step, multi-slice, or integration-heavy work"]
  RootOwner --> ChildSlices["delegates slices to aad-slice-owner"]
  SliceOwner --> InternalWorkers["internal delegation:\naad-implementer / support agents"]
  ChildSlices --> InternalWorkers
  InternalWorkers --> Evidence["implementation, discovery, audit, browser, or failure evidence"]

aad-implementer and support agents are internal execution/evidence targets, not the default top-level terminal route for owned AAD work.

AAD worker loop

These standalone agents participate in a common owner/orchestrator loop.

Typical implementation and failure classification flow. Acceptance remains with the root/slice owner and acceptance auditor.

flowchart TD
  Owner["aad-root-owner / aad-slice-owner"] --> Story["scoped task + acceptance criteria + test commands"]
  Story --> Impl["aad-implementer\nred-green-refactor\nrun targeted checks"]
  Impl --> Result{"PI_RESULT"}
  Result -- "PASS" --> Done["implementation evidence\nready for owner/auditor decision"]
  Result -- "FAIL or BLOCKED" --> Classifier["aad-failure-classifier\nCODE_BUG / TEST_CONTRACT / TEST_BUG / INFRA / SCOPE_GAP / AGENT_LOOP / SECURITY_BLOCKER"]
  Classifier --> Next["NEXT_ACTION\nretry, adjust scope, escalate model, or ask human"]
  Next --> Owner

Browser automation support

chrome-browser-agent chooses the safest browser mode for the task.

flowchart TD
  BrowserTask["browser automation task"] --> NeedsAuth{"Needs login, saved session, profile, passwords, extensions?"}
  NeedsAuth -- "no" --> Headless["browser-chrome-headless\ndisposable Chrome\npublic/simple/parallel checks"]
  NeedsAuth -- "yes" --> Headed["browser-chrome-headed\npersistent Chrome profile\nauth/session tasks only"]
  Headless --> CloseHeadless["close headless instance after use"]
  Headed --> PreserveProfile["do not inspect secrets\nclose only opened tabs"]

Capability matrix

Agent Primary role Write access by prompt/tools Context settings
aad-explorer Read-only discovery and evidence report Prompt says no file modification replace, project context on, skills on
aad-root-owner Own non-trivial root work; slice, delegate to slice owners, integrate results, and decide root done-state Can edit/write for owner artifacts; not hands-on coder by default replace, project context on, skills on, subagent with maxSubagentDepth
aad-slice-owner Own one clear slice end-to-end; coordinate planning, delegation, verification, and integration Can edit/write replace, project context on, skills on, subagent with maxSubagentDepth
aad-auditor Read-only acceptance audit Prompt says read-only except harmless verification commands replace, project context on, skills on
aad-implementer Scoped implementation worker with TDD loop Can edit/write replace, project context on, inherited skills off; injects codex-tools
aad-failure-classifier Narrow failure evidence classifier Read-only for source/test/config; may write task-package report replace, project context on, inherited skills off; injects codex-tools, aad-task-package, aad-failure-classification
chrome-browser-agent Browser automation via browser-chrome skill and MCP Browser side effects only as requested; protects profile secrets replace, project context on, inherited skills off; injects browser-chrome
