Personal workflow infrastructure

Pi agent workflow map

A local owner-led workflow for bounded coding tasks. Owners retain scope and acceptance; implementers and support agents contribute focused work and evidence.

Top-level routing

The terminal assistant chooses the smallest owner boundary that fits the request. Skills support this path but never own the final decision.

1. Classify

Handle a trivial one-step request directly. Route owned changes instead of improvising a worker chain.

→
2. Assign ownership

aad-slice-owner takes one clear slice. aad-root-owner takes cross-cutting or integration-heavy work.

→
3. Integrate evidence

The owner evaluates implementation, review, browser, and test evidence before reporting completion.

Checked-in agents

Six executable definitions are installed from agents/.

Root ownership

aad-root-owner

Plans, slices, delegates, integrates, and decides the root done-state.

Slice ownership

aad-slice-owner

Owns a single bounded slice from scope through verification.

Implementation

aad-implementer

Changes code in a delegated worktree and returns fresh implementation evidence.

Discovery

aad-explorer

Performs read-only codebase exploration and evidence gathering.

Acceptance

aad-auditor

Checks whether acceptance criteria are supported by sufficient evidence.

Browser

chrome-browser-agent

Uses disposable headless Chrome by default and persistent profile state only when required.

Owner loop

The current skills reinforce four reusable stages without creating another orchestration layer.

01

Plan

aad-plan-writing defines acceptance, dependencies, and sequence.

02

Delegate

aad-slicing-and-delegation preserves ownership and explicit write boundaries.

03

Report

aad-reporting returns compact evidence, issues, verdict, and the next-agent brief.

04

Complete

aad-step-completion requires fresh checks before a readiness claim.

✓

Supporting lanes: target-branch work uses aad-git-branching; reusable pipeline friction uses agent-pipeline-feedback; frontend, backend, DevOps, and visual skills add domain-specific evidence.
