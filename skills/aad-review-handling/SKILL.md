# AAD Review Handling

Classify each finding:

- correct and fix now;
- unclear and needs one targeted question;
- incorrect and should be rejected with evidence;
- valid but outside scope and should be tracked separately.

Apply the smallest correct current-scope fix and rerun the affected proof.

After audit fixes, request a focused re-audit of changed or previously failed criteria. Do not restart the full workflow unless the fix changed system integration.

Do not agree performatively, create review rituals, or treat optional suggestions as blockers.
